# Navi 导航站 — 需求文档（PRD）

> 状态：与实现对齐
> 关联：[技术文档](技术文档.md)

本文件描述**做什么（What）**；实现层面的**怎么做（How）**见[技术文档](技术文档.md)。

## 1. 概述

Navi 是一个**极简、可自托管的个人导航站**，融合「搜索起始页」与「带层级标签的网址收藏夹」，支持多账号隔离与配置导入导出。

**成功标准**：用户在任意设备/浏览器登录后，能快速搜索网页、收藏并整理网址、用层级标签与模糊搜索按需查找；管理员可创建并管理账号；同一套代码既能部署到 Cloudflare，也能用 Docker 自托管。

## 2. 动机 / 要解决的痛点

- 跨浏览器、跨设备同步书签麻烦；浏览器书签"好但不够好"。
- 黄页 / 导航类网站广告泛滥。
- 密码管理器记录的是登录页，对特定文章页不友好。

## 3. 用户角色

| 角色 | 能力 |
|---|---|
| **游客**（未登录） | 仅使用极简搜索起始页；无收藏 |
| **普通用户** | 管理自己的网址/标签/搜索引擎/偏好/个性化；改自己的密码与显示名 |
| **管理员**（可多个） | 普通用户的全部能力 + 建号、重置密码、停用/启用、删除、提升其他用户为管理员 |

## 4. 范围

**已纳入**：游客极简搜索页；账号系统（首启向导、管理员建号、多管理员）；网址 CRUD + 抓取 + 批量操作 + 启用/停用；层级标签 + 多标签 + 交集筛选；搜索引擎管理（每引擎可选谷歌/百度搜索建议）；个人设置；JSON 备份与浏览器书签导入导出；**个性化（自定义/Bing 背景图 + 明暗透明度、个性签名、背景音乐播放器）**；**首页键盘快捷键与卡片方向键导航**；**每账号资源数量上限**；可安装 Web App；黑暗模式 + 中英双语；响应式（移动端单列）；安全底线。

**明确推迟（暂不做）**：浏览器扩展/书签小工具一键收藏、公开分享页、2FA / 第三方登录、搜索引擎关键字快捷（`g 关键词`）、访问统计、标签合并、favicon 下载缓存、无头浏览器渲染兜底。

## 5. 功能需求

### 5.1 游客与首页

**游客（未登录）**：只看到极简起始页——居中 Logo + 搜索框 + 内置搜索引擎（Google / Bing / DuckDuckGo），右上角悬停出现「设置/登录」。无收藏。

**登录后首页**（异型 Rail + Canvas 布局，整页固定最大宽度居中、响应式）：

```
┌─────────────────────────────────────────────────┐
│                                         ⚙  头像   │
│                                                   │
│              [ ▾引擎 |  搜索网页…    🔍 ]          │  ← Hero 网页搜索整体下压（引擎选择器在左）
├───────────────┬────────────────────────────────┤
│ [最近|次数|权重|时间] │ [＋筛选标签▾] 已选:[..] 🔍模糊搜索 │  ← 分段条切换
│ • 站点        │ ┌─ 网址卡片网格（favicon+名称+标签）─┐ │
│ • 站点        │ │  [card] [card] [card]           │ │
│ • 站点        │ │  [card] [card] [card]           │ │
│ (单开·数量自适应) │ │         ‹ 1 2 3 ›  分页          │ │
└───────────────┴────────────────────────────────┘
```

要求：
- **网页搜索是独立的一等公民**，与站内标签/收藏查找完全分离；引擎选择器在搜索框**左侧**；仅下拉切换引擎（不做关键字快捷）。**Hero（slogan + 搜索框）整体下压**释放上方视觉空间、降低视觉压力，视点落在视口偏上（Chrome 新标签页与 Bing 之间）；随视口高自适应（矮屏收敛、高屏封顶）。
- **搜索建议**：当前引擎若配置了建议来源，输入时由本站接口返回联想词（最多 10 条），列表与输入框左对齐；未配置、输入为空或内容看起来像网址时不请求。↑↓ 移动高亮，Enter 选中并搜索，Esc 先关闭列表、再按才清空失焦。游客内置引擎不提供建议。
- **左侧分段面板区（单开）**：最近访问 | 访问次数 / 自设权重 / 创建时间 四榜单，**上方一行等分四段做切换、下方只展示选中的那一个面板**并撑满侧栏可用高；**永远恰好一个展开**（默认最近访问，点当前选中段无效，无全收起态），选中项仅会话内、不持久化。面板条数按视口高度自适应（同时也作为榜单拉取的 limit）。
  - **最近访问**：按最近访问时间倒序；右上角「✕ 清除」一键清空，行内可单个移除。
  - **访问次数**（按次数倒序，0 次不进榜）、**自设权重**（按权重倒序，未设权重不进榜）、**创建时间**（新→旧）：**只读榜单，不支持清空/单个清除**。
  - **手机（<1024px）**：侧栏坍缩到网址列表**上方**堆叠、允许滚动，分段条 + 单面板形态不变。
- **查找收藏**（右下大区）：
  - **筛选标签触发器在最左**，点击浮出**级联菜单**（逐层向右展开：默认显示第一级，`›` 标识有子级，点击向右开新列）；浮层悬浮于网格之上、**不挤占网格空间**。
  - **父级标签可直接勾选**（点名字=选中，点 `›`=展开子级）；父级选中即含其全部子级。
  - **多选取交集**（同时命中所有已选标签），支持「清除全部」；标签多时菜单内有「找标签」搜索。
  - **模糊搜索框范围跟随已选标签**：选了标签→只在该结果集内搜；未选→全局搜索。匹配网站名称/说明/网址。
  - 结果为**网址卡片网格**，支持权重、名称、最近访问、最近添加、访问次数等排序，**分页**；首页筛选行提供排序切换，初值取自默认排序偏好，**切换仅当前会话生效、不写回偏好**。
  - 网格支持方向键按实际行列移动焦点；首次按方向键聚焦第一张卡片，`Enter` 打开当前网址。
- **快速添加网址**：首页/顶部提供快捷入口（高频动作）。
- **空状态**：新用户零收藏时给引导。
- **默认不一次性展示全部网址**（减轻查询压力、避免页面拥挤）。

### 5.2 网址收藏

- 字段：网址、名称、说明、favicon、权重（排序用）、标签（多个）、启用状态、自动记录的访问时间/次数。
- **新增 / 编辑 / 删除**；新增时点「抓取」自动回填名称、说明、favicon（用户可手改）。
- **启用 / 停用**：可将网址标记为停用；停用的网址不计入「最近访问」、可按状态（启用/停用/全部）筛选。
- **排序**：权重 / 名称 / 最近添加 / 最近修改 / 最近访问 / 访问次数；**分页**。
- **批量操作**：批量删除；批量给一批网址增删一个或多个标签。
- 点击网址记录访问时间并累加访问次数（驱动"最近访问"与访问次数排序）。

### 5.3 标签

- **层级标签**（路径式，如 `技术/python`，深度不限）。
- **一个网址可有多个标签**。
- 创建：给网址打标签时可现场新建（可指定父级）；也有独立标签管理页。
- **重命名 / 移动（改父级）/ 删除 / 批量删除**。
- **删除父标签 = 级联删除整棵子树**（删除前提示影响数量）；网址只是失去这些标签，**不会被删**。
- 按标签筛选时"**父含子**"（选父标签即查出其所有子级下的网址）。

### 5.4 搜索引擎

- **每个账号独立的引擎列表**：建号时预置 Google / Bing / DuckDuckGo；之后用户自行增删改、拖拽排序、设默认。游客用内置默认。
- 自定义引擎：名称 + 查询地址模板（`{query}` 占位）+ 可选图标 + **可选搜索建议来源**（无 / 谷歌 / 百度）。来源按引擎单独配置，不是全局一份；预置引擎与游客内置引擎默认为「无」，存量空值按「无」处理，不按名称或地址推断。不支持自定义建议接口。建议来源为非官方接口，失败时列表为空，可随时改回「无」。
- 仅下拉切换（不做关键字快捷；引擎数量不会太多）。

### 5.5 个人设置 + 主题 / 语言

- **账户**：改密码、改显示名。
- **偏好**：最近访问数量（默认 8）、列表每页数量、默认排序。
- **黑暗模式**：跟随系统 + 按钮切换（不入用户配置，存浏览器本地）。
- **语言**：中 / 英双语，按浏览器 cookie 的 locale 判断（中文环境→中文，其余→英文）+ 按钮切换（不入用户配置）。

### 5.6 账号与后台

- **不开放注册**。全新部署时通过**首启设置向导**创建第一个管理员；一旦存在用户该向导永久关闭。
- **多管理员**：可把普通用户提升为管理员。
- 管理员能：建号（邮箱 + 设初始密码）、重置密码、停用/启用、删除账号。
- 所有账号以**邮箱**为标识；普通用户可改自己的密码/显示名/偏好，邮箱由管理员管理。
- **新用户首次登录强制改一次密码**。
- 删除账号 → 其网址/标签/引擎/偏好一并删除。

### 5.7 导入 / 导出

- **JSON 导出**：本账号的「网址（含权重、标签、启用状态）+ 标签层级 + 搜索引擎 + 偏好」为带版本号的完整备份（不含密码、不含他人数据）。
- **HTML 导出**：生成通用 Netscape 书签 HTML；标签路径映射为多层目录，可导入主流浏览器。
- **导入**：按文件内容自动识别 Navi JSON 或浏览器书签 HTML；默认**合并**（网址按 URL 去重、标签按路径去重），也支持 replace。HTML 目录映射为层级标签，同一 URL 位于多个目录时合并为一条网址并关联多个标签。
- HTML 只包含浏览器书签可表达的网址、标题与目录；使用 replace 导入 HTML 时，仅替换网址与标签，未提供的搜索引擎和偏好保持不变。
- **二次确认**：导入与导出都是敏感操作（整库读出 / 覆盖），执行前需再次输入**当前登录密码**确认；密码错误则拒绝并提示，不执行任何读写。

### 5.8 个性化（背景 / 签名 / 音乐）

- **背景图**：三种模式——无 / Bing 每日壁纸 / 自定义图片 URL；分别为**浅色与深色主题**设置背景可见度（透明度），预览即时生效。
- **个性签名**：首页可显示一句个性签名（slogan）文本，支持行内标记——`<b>` 加粗、`<i>` 斜体、`<s>` 删除线、`<c=#hex 或颜色名>` 着色（大小写不敏感、可嵌套；不合法的标记原样显示为字面文字）；可从本地系统字体中挑选展示字体（字体选择只保存在本浏览器）。
- **背景音乐**：可维护一个小型播放列表（最多 20 首，含地址与名称），支持拖拽排序；首页提供播放器（播放/暂停/上下曲/进度/音量/循环模式）；音量与循环偏好记在本浏览器。

### 5.9 键盘快捷键

首页提供一组键盘快捷键，`?` 打开帮助面板列出全部可用键位；修饰键按平台显示 ⌘ / Ctrl。

| 键 | 动作 | 前提 |
|---|---|---|
| `/`、`⌘/Ctrl+K` | 聚焦网页搜索框 | — |
| `s` | 聚焦站内模糊搜索 | 已登录 |
| `n` | 新增网址 | 已登录 |
| `p` | 播放 / 暂停背景音乐 | 已登录 |
| `↑` `↓` `←` `→` | 在网址卡片网格中按实际行列移动焦点 | 已登录且网格有结果 |
| `Enter` | 打开当前聚焦的网址卡片 | 卡片已聚焦 |
| `Esc` | 若搜索建议列表已打开则先关闭；否则清空并失焦当前输入 | — |
| `?` | 打开快捷键帮助 | — |

约定：单键快捷键在输入框/文本域内不触发（让位于打字），`⌘/Ctrl+K` 例外；中文输入法组合中（IME composing）一律不触发。

### 5.10 资源数量上限

为防止脚本化的大批量刷库，每个账号的资源数量设**足够高、正常使用碰不到**的上限：网址 10000、标签 1000、搜索引擎 100、音乐播放列表 20 首、个性签名可见文本 80 字（格式标记不计）、含标记的原始长度 1000 字。超限时创建/导入被拒并提示。导入（尤其 replace 模式）按导入后的最终数量预检，超限则整批不写、避免留下半份数据。

## 6. 非功能需求

- **部署**：Cloudflare（Serverless）与 Docker / 自托管**从第一天起完全对等**。
- **安全底线**（要求层面，落地见技术文档）：密码不得明文存储；账号间数据严格隔离；登录需防爆破；防 CSRF；**「抓取」是服务端请求用户提供的 URL，必须防 SSRF**（拦截内网/本地/云元数据等）；**导入导出等整库级敏感操作需当前密码二次确认**。
- **国际化**：中英双语；**黑暗模式**：跟随系统 + 可切换。
- **响应式**：桌面异型布局在移动端坍缩为单列（搜索 → 面板分段条（单开、默认最近访问） → 查找）。
- **可安装性**：提供 Web App Manifest、Apple Touch Icon 与 maskable 图标；支持的浏览器可安装为 standalone Web App。
- **性能/数据加载**：按需分页加载，不一次性拉取全部。
- **可维护性**：需求与技术分文档记录，并**随实现更新保持一致**；技术选型与架构需可追溯（见技术文档）。
